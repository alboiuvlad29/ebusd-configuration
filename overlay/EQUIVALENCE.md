# Equivalence of the first build with the hand-made `local/` files (2026-10-03)

Compared per message (name, read/write/passive kind, condition, bus ID, field types/values/units,
level, poll priority) for the four files that were hand-edited: `08.hmu.HW5103`, `15.ctlv3` (built from
`15.ctlv2.tsp`), `26.vr_71`, `76.vwzio`.
Command: `python3 overlay/localbuild.py compare dist/local/en/vaillant <old local folder> <files…>`

**Identical:** all 152 poll priorities, all 12 read-only installer copies, `HwcPreset`, `HwcEcoTempDesired`,
`HwcEcoChargeHyst`, `GreenIQ` (read+write), `MultiInputSetting` (UIN), `MultiRelaySetting`, all hmu
messages and IDs that were in the old file. The three removed messages (`Status`, `Status02`, `Status16`) are
not generated by the PR #660 sources at all, so the removal table has no effect (it only warns).

**Differences (all intended or cosmetic):**

| File | Difference | Reason |
|---|---|---|
| 08.hmu.HW5103 | new `Hours`, `HoursHc`, `HoursHwc` (b51a 05ff3240/41/44) | adopted from #604 |
| 08.hmu.HW5103 | new `BuildingCircuitPressure` (b514 052a03ffff) | adopted from driesenj fork |
| 08.hmu.HW5103 | `LastError`, `FaultHistory1..9`: column 33 (name of the trailing 2-byte ignore field) is `ign` instead of empty | TypeSpec names every field; the ignored bytes are not decoded, no behaviour change |
